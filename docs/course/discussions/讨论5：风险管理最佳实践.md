# 讨论5：风险管理最佳实践

## 迭代一风险

### 李健博：

| 风险                             | 风险描述                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| 风险一：GPU 显存不足             | 开发环境 GPU 显存有限，运行生成模型时可能出现显存溢出，影响调试和开发效率。 |
| 风险二：多视角图像生成算法不成熟 | 现有科研工作中，多视角图像生成 CAD 的相关算法尚不成熟，视角间几何一致性与信息融合等问题仍有待解决，可能缺乏可直接复用的成熟方案，增加算法选型与开发难度。 |
| 风险三：Skill 与 Tools 编写困难  | 对 DSH 插件的 Skill、Tools 编写规范及调用机制不够熟悉，可能导致工具接口设计、参数传递和功能集成耗时较长。 |
